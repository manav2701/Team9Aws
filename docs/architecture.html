Shifa Architecture

Shifa is a care navigator. It helps a patient choose the right next step (wait, see a doctor, or go to the ER), books it, and never diagnoses or prescribes.

The system

Four services

Lambda · web

workshop-shifa-web

Next.js chat app on AWS Lambda with a public HTTPS link. Its server routes call AWS so the browser never holds credentials.

AgentCore · agent

HealthAgent

Strands agent on AgentCore Runtime with Memory. Claude Sonnet 5 on Bedrock reasons and chooses tools. A red-flag rule sends emergencies to the ER.

Lambda · tools

workshop-health-tools

Five tools behind the AgentCore Gateway: patient profile, medication check, provider search, booking, visit summary.

Lambda · voice

workshop-shifa-calls

Phones the clinic through Twilio. Claude Haiku 4.5 holds the conversation; the result is saved and announced.

One question, end to end

  1. The patient types "headache and blurry vision for 3 days" in the web app.
  2. The web Lambda sends it to HealthAgent with the patient id.
  3. The guardrail checks the question. It's allowed.
  4. Claude reads the patient's record (hypertension, amlodipine) and the triage guidance through the tools.
  5. The answer: see a doctor within 24 hours, with an offer to find a neurologist and book, ending with "This is not medical advice."
  6. Optional: "Call now" has the voice Lambda phone the clinic and report the slot.

Unsafe question: the guardrail blocks it at step 3 and the patient gets a polite refusal with a safe next step. Red flag: Claude says to go to emergency care now and no booking tool is called.
